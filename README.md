# LagLess

A clean default Android starter project built with Kotlin and Jetpack Compose (Material 3).

## Build

```bash
./gradlew assembleDebug
```

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose with Material 3
- **Build System:** Gradle Kotlin DSL
- **Minimum SDK:** 26 (Android 8.0)
- **Target SDK:** 35
